# 업체 이관 협업 시스템 (Supplier Changeover)

외주 협력업체 **생산처 변경(반납/이관) 프로세스**를 여러 업체가 함께 진행·관리·협의하는 협업 도구입니다.

## 주요 기능

- **업체 가입/승인**: 회사·아이디·비밀번호로 자유 가입 → 주관사(시스템 관리자) 승인 후 사용
- **역할 체계**: 시스템 관리자(주관사) / 회사 관리자 / 일반 사용자
- **BPMN 프로세스 엔진**: 승인(XOR) 분기, 병렬(AND) 게이트를 지원하는 업무 흐름 자동 진행
  - 내장 템플릿: "외주 협력업체 생산처 변경 (반납 접수)" — 반납 공문 접수 → 반납 결정 승인 → 대상품목/금형/검사구/설비/대차·용기 조사 → 양산처 선정 → 이관(품질/재고/금형·설비 이동/잔여 원자재) → 완료 보고 → 대여자산공증
- **템플릿 편집기**: React Flow 기반 그래픽 편집 (노드 추가/연결/승인 조건/소요일)
- **일정 관리**: 시작일 기준 자동 일정 산출, 간트차트·칸반·프로세스 흐름도·D-day/지연 표시
- **협업**: 과제별 업무일지(파일 첨부) + 협의 댓글 + 인앱 알림
- **과제 배정**: 주관사가 업체 배정 → 회사 관리자가 담당자 지정

## 기술 스택

Next.js 14 (App Router) · TypeScript · Prisma · PostgreSQL · React Flow

## 로컬 실행

```bash
cp .env.example .env   # DATABASE_URL 등 설정
npm install
npx prisma db push     # 스키마 반영
npm run seed           # 관리자 계정 + 내장 템플릿 생성
npm run dev
```

초기 관리자 계정: `admin` / `admin1234` (환경변수 `ADMIN_LOGIN_ID`, `ADMIN_PASSWORD`로 변경 가능 — **운영 배포 시 반드시 변경하세요**)

## Railway 배포

1. Railway에서 새 프로젝트 생성 → 이 GitHub 저장소 연결
2. **PostgreSQL** 서비스 추가
3. 앱 서비스의 Variables 설정:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}` (참조 변수)
   - `SESSION_SECRET` = 긴 랜덤 문자열
   - `ADMIN_PASSWORD` = 초기 관리자 비밀번호 (선택, 기본 admin1234)
   - `UPLOAD_DIR` = `/data/uploads` (볼륨 사용 시)
4. (권장) 파일 첨부 유지를 위해 **Volume**을 `/data`에 마운트
5. 배포 — `npm start`가 자동으로 `prisma db push` + 시드 실행 후 서버를 시작합니다.

## 사용 흐름

1. 관리자(주관사)가 로그인 → 협력업체 가입 신청을 **관리** 메뉴에서 승인
2. **프로세스 템플릿**에서 흐름 확인/편집 (복제 후 수정 가능)
3. **새 이관 프로젝트** 생성 (템플릿 + 시작일) → 과제·일정 자동 생성
4. 과제별로 담당 업체 배정 → 업체가 진행하며 업무일지·첨부로 결과 공유
5. 승인 과제(반납 결정 등)는 관리자의 **승인/반려**에 따라 프로세스가 자동 분기
6. 간트/칸반/흐름도에서 전체 진행 현황을 모두가 공유
